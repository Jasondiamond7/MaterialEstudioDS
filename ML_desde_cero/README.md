# ML desde cero · Salud mental en tecnología

Proyecto progresivo para aprender Machine Learning con un único dataset real.

**Dataset:** [OSMI Mental Health in Tech Survey (2014)](https://www.kaggle.com/datasets/osmi/mental-health-in-tech-survey) → `data/survey.csv` (1.259 respuestas, 27 columnas).
**Objetivo:** predecir `treatment` (¿buscó tratamiento de salud mental?).

> Ejercicio de aprendizaje, no una herramienta de diagnóstico.
