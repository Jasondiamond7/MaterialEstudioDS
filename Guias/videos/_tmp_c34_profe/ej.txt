 Para resolver en papel, con calculadora (teclas ln y log) · soluciones paso a paso al final

 Cómo usar esta guía
 • Escribe el número del bloque y del ejercicio, y tu desarrollo completo.
 • Para log2 usa log2(x) = ln(x) / ln(2) = ln(x) / 0.693.
 • Nivel: ★ directo · ★★ 2 o 3 pasos · ★★★ integra varios conceptos.
 • Los Bloques 1 y 4 usan el árbol y los números de la guía (página 1).

Bloque 1 Recorrer el árbol de la clase ★

Usa el árbol de profundidad 3 de la guía.

        fuga?
2 Cliente B: reclamó, 30 llamadas, 2 fallas. ¿Hoja y probabilidad?
3 Cliente C: no reclamó, 3.000 segundos, CLV 500. ¿Hoja y probabilidad?
4 Calcula el lift de la hoja del cliente B (tasa general 15.7%) y escribe su regla en una frase de negocio.

Bloque 2 Impureza a mano ★

Bloque 3 Elegir el corte ★★

fugan), derecha 100 (20 fugan).

2 Calcula el Gini de cada hijo, el Gini ponderado y la ganancia de los cortes A y B.
3 ¿Cuál elige el árbol? ¿Qué tienen de especial los hijos del corte B?
4 ★★★ Repite el corte A con entropía en vez de Gini. ¿Cambia la elección?

#  Solución

1  reclamos ≤ 0.5 sí → segundos ≤ 934 sí → antigüedad ≤ 28.5 no → hoja de 340 clientes: 43%.

2  reclamos ≤ 0.5 no → frec_llamadas ≤ 57.5 sí → numero_fallas ≤ 0.5 no → hoja de 149 clientes: 94%.

3  reclamos ≤ 0.5 sí → segundos ≤ 934 no → clv ≤ 61.3 no → hoja de 2.359 clientes: 4.5%.

4  Lift = 0.94 / 0.157 = 6.0. Regla: «clientes que reclamaron, usan poco el servicio (57 llamadas o menos) y tuvieron fallas

   técnicas: 94% se fuga». Prioridad 1 para retención.

Bloque 5

#  Solución

1  Profundidad 6: tiene el mayor AUC de validación (0.911).

2  Brechas: prof. 3 → 0.005 · 6 → 0.029 · 10 → 0.103 · sin límite → 0.173. La brecha crece con la profundidad: más

Bloque 6

#  Solución

1  α = 0.001: T1 = 0.08 + 0.030 = 0.110 · T2 = 0.12 + 0.006 = 0.126 → gana T1. α = 0.004: T1 = 0.08 + 0.12 = 0.20 · T2 =

   0.12 + 0.024 = 0.144 → gana T2.

2  0.08 + 30α = 0.12 + 6α → 24α = 0.04 → α = 0.00167.

3  Para gerencia, probablemente el de 15 hojas: se entiende en una lámina y pierde poco AUC (0.883 vs 0.909). Si el

   objetivo es predecir, el de 36 hojas. Depende de para qué es el modelo.

Bloque 7

#  Solución

1  segundos: 0.92 − 0.89 = 0.03 · edad: 0.92 − 0.915 = 0.005. segundos importa seis veces más.

2  Con 2.654 valores, clv ofrece muchísimos umbrales; por azar alguno reduce la impureza, y la importancia por impureza

   lo premia. Al desordenarla en datos nuevos, el AUC casi no cae: el modelo no la necesitaba tanto.

3  Porque sobre el entrenamiento el modelo ya memorizó: desordenar una variable que memorizó hace caer el AUC

   aunque no generalice.

Bloque 8

#  Solución

1  Nuevo umbral: log(1 + 934) = 6.84. Ningún cliente cambia de lado: la transformación es monótona y conserva el orden.

2  B = 10: 0.4 + 0.6/10 = 0.46 · B = 200: 0.4 + 0.6/200 = 0.403 · piso: ρσ² = 0.4.

3  √12 ≈ 3 variables por corte. Así los árboles se parecen menos entre sí (baja ρ) y el promedio reduce más la varianza.
